#🛒 Amazon_Dashboard

🚀 Excited to showcase my Amazon Global Sales Dashboard created in Power BI!

📊 Key Highlights:
• Total Amount
• Total Quntity
• Total Price
• Shoping Cost
• OrderID


📈 Dashboard Insights:
✔ Product by Units analysis
✔ Region-wise sales performance (Map view)
✔ Payment & customer Name
✔ SellerID & Brand
✔ Profit analysis by customer
✔ Payment Method by Order Status


This dashboard helps in identifying top-performing markets, profitable products, and areas needing improvement for better business decisions.
🛠 Tools Used: Power BI | Data Visualization | Dashboard Designing
